### Resumo
O nosso sitema busca atrâves de uma inteface limpa ajudar os usuários e admintradores a monitorarem os trens e metros, sendo assim, nosso difercial conciste em ofercer todo esse serviço de maneira facil, com interface intuitiva e organizadas para nossos usuários.

### Decisão técnica
Stack a ser utilizada é baseada no HTML, sendo usado para estruturar todas as páginas do sistema, o CSS para podermos personalizar as telas e adaptarmos para todos os tipos de dispositivos, o JavaScript usado para validação dos formulários e interações do site e será utilizado também o Bootstrap que foi escolhido para agilizar o desenvolvimento.
