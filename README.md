# SuperTrain
* * Sistema web para gerenciamento e acompanhamento de operações ferroviárias.
Objetivo
O SuperTrain centraliza informações sobre trens, rotas, sensores, usuários e indicadores operacionais, facilitando o acompanhamento e a organização da operação ferroviária.
Principais funcionalidades
- Dashboard: visão geral da operação e principais indicadores.
- Trens: cadastro e gerenciamento da frota.
- Rotas: cadastro, edição, consulta e exclusão de rotas.
- Sensores: configuração e acompanhamento dos sensores.
- Relatórios: indicadores, gráficos e dados operacionais.
- Perfil: gerenciamento dos dados e preferências do usuário.
- Cadastro e recuperação de senha: criação de contas e redefinição de senha.
Níveis de acesso
O sistema possui dois tipos de usuário:
- Gestor: acesso às funções administrativas.
- Cliente: acesso às funções gerais do sistema.
A autenticação utiliza sessões PHP e as senhas são armazenadas de forma segura com hash.
